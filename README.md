# 고령 보행자 사고다발지역 × 노인보호구역 좌표 대조 분석

「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」(2026) 분석보고서의 분석 코드입니다.
보고서에 인용한 수치는 아래 순서대로 실행하면 그대로 다시 나옵니다(`out/results*.json`).

## 환경

```
Python 3.13
pandas / numpy / matplotlib
```

지도 API·유료 서비스·API 키를 쓰지 않습니다. 그림의 한글 글꼴은 macOS 기본 `AppleGothic`이며,
다른 OS에서는 `matplotlib.rcParams["font.family"]`를 그 OS의 한글 글꼴로 바꾸면 됩니다.

## 실행 순서

```bash
# (1) 원자료 내려받기 — data/ 에 CSV가 생긴다 (공공데이터포털 표준데이터)
python3 01_download_datagokr.py '[["15029185","data/전국교통사고다발지역표준데이터_폴리곤제외.csv"],["15034532","data/전국노인장애인보호구역표준데이터.csv"]]'
#     주민등록 인구통계는 https://jumin.mois.go.kr 에서 「연령별 인구현황(5세 단위, 시군구)」
#     2026년 8월 기준을 내려받아 data/주민등록_5세단위_시군구_202608.csv 로 둔다.

# (2) 본분석 — out/ 에 fig1~fig5, table_*.csv, results.json
python3 02_analyze.py

# (3) 반복 출현 분석 — out/ 에 fig6, table_repeat_points.csv, results_persistence.json
python3 03_persistence.py
```

원자료(`data/`)는 저장소에 넣지 않았습니다. 공개 원자료이므로 (1)로 받으면 됩니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `01_download_datagokr.py` | 공공데이터포털 표준데이터 페이지의 공개 다운로드 경로로 CSV를 받는다 |
| `02_analyze.py` | 표본 확정(2024년 지정분) → 장소 유형 분류 → 하버사인 전수 거리행렬 → 커버율·역방향 지표 → 시군구 집계 → 설비 현황 → 우선 후보 산출 |
| `03_persistence.py` | 2021~2024년 네 해를 100m 단일연결로 군집해 같은 자리를 잇고, 반복 횟수 × 보호구역 거리 2축으로 최우선 후보 205곳을 뽑는다 |
| `figprint.py` | 그림을 인쇄 폭(mm)에 맞춰 그리는 도우미 |
| `out/` | 그림 6장, 표 CSV, 수치 원값 JSON |

## 방법 요약

- 표본: 사고다발지역 선정기준이 2021년에 바뀌어 2021년 이후만 사용.
- 장소 유형 분류: 정규식 규칙 7범주(`02_analyze.py`의 `PLACE_RULES`).
- 거리: 하버사인 공식 직접 구현(지구 반경 6,371,008.8m). 외부 지오코딩·경로탐색 API 미사용.
- 군집: 100m 임계 단일연결(union-find) 직접 구현.
- 통계: 기술통계(구성비·중앙값·평균·분포). 회귀·인과추론·예측모형 없음.
- 원자료에 개인정보·개인위치정보 항목 없음(사고 지점·보호구역 좌표는 시설·교차로 좌표).
